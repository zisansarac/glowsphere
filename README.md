
### 🎨 GlowSphere

*A minimal social platform for artists and creatives*  
Inspired by **Pinterest** and **Blogger**

#### 🧭 Purpose  
To create a space where art lovers can express themselves and explore creativity freely.

#### ⚙️ Tech Stack  
🖥️ **Frontend:** React, TypeScript, Tailwind CSS  
🧩 **Backend:** Appwrite (BaaS)

#### ✨ Features  
- 🎨 Upload & share artworks  
- 🖼️ Explore artistic content feed  
- 🧩 Filter by categories and tags  
- 📱 Responsive, clean UI  
- 👤 User authentication & profiles
