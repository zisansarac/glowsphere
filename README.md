#  GlowSphere

GlowSphere, sanatseverleri ve yaratıcıları bir araya getirmeyi amaçlayan sosyal paylaşım platformudur. Pinterest ve Blogger'dan ilham alınarak geliştirilmiştir. Kullanıcılar sanat eserlerini paylaşabilir, ilham alabilir ve yaratıcı topluluklarla etkileşime geçebilir.

##  Proje Amacı

Sanata ve yaratıcılığa değer veren kullanıcıların kendilerini ifade edebilecekleri, özgün bir sosyal medya deneyimi sunmak.

##  Kullanılan Teknolojiler

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Appwrite (BaaS)


##  Özellikler

- Sanat eseri paylaşımı (resim, açıklama, etiket)
- Sanatsal içerik akışı
- Kategori bazlı filtreleme
- Responsive ve estetik arayüz
- Kullanıcı girişi & profiller
