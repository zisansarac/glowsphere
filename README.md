#  GlowSphere

GlowSphere, sanatseverleri ve yaratıcıları bir araya getirmeyi amaçlayan sosyal paylaşım platformudur. Pinterest ve Blogger'dan ilham alınarak geliştirilmiştir. Kullanıcılar sanat eserlerini paylaşabilir, ilham alabilir ve yaratıcı topluluklarla etkileşime geçebilir.

##  Proje Amacı

Sanata ve yaratıcılığa değer veren kullanıcıların kendilerini ifade edebilecekleri, özgün bir sosyal medya deneyimi sunmak.

##  Kullanılan Teknolojiler

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Appwrite (BaaS)


##  Özellikler

- Sanat eseri paylaşımı (resim, açıklama, etiket)
- Sanatsal içerik akışı
- Kategori bazlı filtreleme
- Responsive ve estetik arayüz
- Kullanıcı girişi & profiller

# 🎨 GlowSphere

**GlowSphere** is a social sharing platform designed to bring together art lovers and creatives.  
Inspired by platforms like **Pinterest** and **Blogger**, it allows users to share artworks, get inspired, and interact with creative communities.

---

## 🎯 Project Purpose

To offer a unique and expressive social media experience for users who value art and creativity.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS  
- **Backend:** Appwrite (BaaS - Backend as a Service)

---

## ✨ Features

- 🎨 Share artworks (image, description, tags)
- 🖼️ Artistic content feed
- 🧩 Filter by categories and tags
- 📱 Fully responsive and aesthetic UI
- 👤 User authentication & profile management
